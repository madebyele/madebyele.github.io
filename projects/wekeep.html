01 · Overview

화면 리뉴얼과
이후 운영을 함께 고려

당시 구성된 모든 메뉴 페이지의 PC·모바일 화면을 단독으로 퍼블리싱하면서 콘텐츠 추가와 변경에 대응할 수 있는 공통 구조를 고려했습니다.

Adobe XD 디자인을 기준으로 반응형 UI를 구현했습니다. 반복 레이아웃을 공통 섹션으로 분류하고 SCSS 변수·믹스인으로 Header/Footer, 버튼, 레이아웃과 Breakpoint의 스타일 규칙을 정리했습니다.

02 · Context / Problem

리뉴얼에서 확인한 과제

  1. 01

    정보량이 많은 화면의 반응형 배치

    정보가 많이 나열되는 화면에서도 화면 크기에 맞춰 콘텐츠가 유연하게 배치되도록 구성해야 했습니다.

  2. 02

    OS별 CSS 호환성

    iOS·Windows·Android에서 발생하는 CSS 호환성 차이를 확인하고 공통 UI의 표시 상태를 조정해야 했습니다.

  3. 03

    콘텐츠 변경 대응

    리뉴얼 이후에도 콘텐츠 추가와 변경이 이어질 수 있어 재사용할 수 있는 레이아웃 기준이 필요했습니다.

03 · My Role

퍼블리싱 담당 범위와
협업 범위

My Responsibility

전체 페이지 단독 퍼블리싱

  • 당시 모든 메뉴 페이지의 PC·모바일 마크업과 스타일 단독 구현
  • SCSS로 Header/Footer, 버튼, 레이아웃, Breakpoint 공통화
  • Flexbox를 활용한 정보량이 많은 화면의 유연한 반응형 배치
  • Swiper 기반 활성 메뉴·슬라이더 및 JavaScript/jQuery 기반 스크롤 애니메이션·모바일 메뉴·탭·Flow 메뉴·Form UI 구현
  • iOS·Windows·Android의 CSS 호환성 차이 조정 및 화면별 UI 확인

Collaboration

디자인·개발 담당자와 협업

Adobe XD 디자인 수령 → 퍼블리싱 → Git 커밋 → 개발 작업 → 디자인 1차 검수 → 기획·개발 2차·최종 검수 순서로 진행했습니다. 협업 도구로 Git, Jira, Slack을 사용했습니다.

이 페이지는 본인이 담당한 퍼블리싱 범위만 설명하며 기획·디자인·개발 업무를 개인 성과로 포함하지 않습니다.

04 · Approach

리뉴얼 화면을 구현한 과정

  1. 01

    Flexbox로 유연한 반응형 배치

    정보량이 많은 화면은 콘텐츠 구조를 유연하게 설계하는 것이 과제였습니다. Flexbox를 활용해 PC·모바일 화면 크기에 맞춰 배치가 조정되도록 구현했습니다.

  2. 02

    OS별 CSS 호환성 조정

    iOS·Windows·Android에서 발생하는 CSS 호환성 차이를 확인하고 스타일을 조정했습니다. Bootstrap은 일부 공통 UI 및 호환성 개선에 적용했습니다.

  3. 03

    공통 UI와 레이아웃 재사용

    Header/Footer, 버튼, 레이아웃과 Breakpoint를 SCSS로 공통화했습니다. 신규 페이지는 기존 레이아웃을 재사용하고 좌우 배치 등을 수정하여 제작 효율을 높였습니다.
